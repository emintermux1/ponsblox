Frequently asked questions

Answers to the questions we get most about the FomoScan social trading API.

FomoScan is a social trading API that connects crypto wallets to the traders behind them. If your product shows wallet activity, FomoScan tells you who that wallet belongs to, who follows them, and how they have performed. Teams use it to build leaderboards, social feeds, trader profiles and copytrading features without building and maintaining the underlying data pipeline themselves.

Every link between a wallet address and a social account is verified rather than guessed. We only return a match when it has been proven, so you are never showing your users an address that merely looks like it belongs to someone. The mapping works in both directions: give us a handle and we return the wallets that person controls, or give us a wallet address and we return the person behind it.

FomoScan covers Solana, Base and BNB Chain today. You do not need to tell us which chain an address belongs to, we work it out from the address itself. More chains are added based on what customers ask for, so if you need one that is not listed, get in touch and tell us.

Every lookup reflects the current verified state at the moment you ask, rather than a snapshot rebuilt on a schedule. Broadcast data reaches you in under 50 milliseconds. Traders who have opted out are never returned, and that takes effect immediately rather than at the next refresh.

You buy a monthly balance of units and spend it across any endpoint you like. There is no feature gating between plans, so a Starter customer reaches exactly the same endpoints as an Enterprise one. The difference is how many units you get and how fast you can spend them. If you run out mid-month you can top up rather than being cut off.

Most teams have something working the same day. It is a plain REST API with flat JSON responses and a full OpenAPI spec, so there is nothing unusual to learn and no SDK you are forced to adopt. If you get stuck, every paid plan includes support from the people who built it.
